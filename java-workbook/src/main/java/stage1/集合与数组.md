# 数组

## 数组初始化声明
```java
   int[] s = new int [5]
   int[] s = new int [] { 1, 2, 3, 4, 5 }
   int[] s = { 1, 2, 3, 4, 5}
   int[] s; s = new int[5]   √
   int[] s; s = {1, 2, 3, 4, 5}  ×
```
## 数组属性方法
数组只有length 长度属性没有任何方法
需要借助Arrays工具类来处理相关操作，数据转换通常使用Arrays.steam()转流式处理

## Arrays常用方法
Arrays.toString(arr)	打印数组内容，返回字符串
Arrays.asList(arr)	数组转 List（⚠️ 坑：固定大小，底层还是原数组）
Arrays.sort(arr)	排序（基础类型：快排；对象：TimSort）
Arrays.binarySearch(arr, key)	二分查找，前提：数组必须先排好序
Arrays.copyOf(arr, newLength)	拷贝数组，可截断 / 扩容
Arrays.copyOfRange(arr, from, to)	区间拷贝 [from, to)，左闭右开
Arrays.fill(arr, val)	全部填充同一个值
Arrays.equals(a1,a2)	比较两个数组元素是否全部相等（== 只是比较地址）
Arrays.stream(arr)	转为 Stream 流！衔接你刚学的流式 API
Arrays.deepToString(arr)	打印二维 / 多维数组
Arrays.deepEquals(a1,a2)	多维数组对比


## 访问&循环
```java
   // 元素方法使用索引下标index
   int[] arr = {1, 2, 3}; 
   arr[0] // 1

   // 循环通常使用for
   for(int i = 0; i < arr.length; i++) {
      System.out.print(arr[i])
   }

   // 元素访问增强for, 数组没有使用iterator, 也是直接编译成上方的模式
   for(int i : arr) {
      System.out.print(i)
   }

```

# 集合

## 为什么要有集合 collection?
1. 因为数组定长, 无法扩容，只能重新声明
2. 中间插入效率低下
3. 类型单一， 不支持泛型

## 集合分类
List 有序列表,  通常使用ArrayList
Set  无序列表,  通常使用HashSet
Map  映射列表,  通常使用HashMap

## List初始化声明
```java
   List<String> l = new ArrayList<>()
```
## List 常用方法
add 添加元素
remove 移除元素 
size   长度获取

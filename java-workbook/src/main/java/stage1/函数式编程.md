# 匿名类
没有类名，没有构造函数，但是可以初始化实例化, 使用 new 父类/ 接口() {}
```java
   // 直接使用的类
   interface P {
     public String use(String a);
   }


  P s = new P() {
    @Override()
    public String use(String a) {
      
    }
  }

  // 等价于
  
  class MyP implements P {
    @Override()
    public String use(String a) {

    }
  }
   
  P s = new MyP()

```

## Lambda
Lambda 只能用于 **函数式接口（只有一个抽象方法）**

```java
  
  interface Consumer {
    public void accept(String s)
  }

  Consumer<String> consumer = new Consumer<String>() {
      @Override
      public void accept(String s) {
          System.out.println(s);
      }
  };

    // 【版本2】改成Lambda完整版
    Consumer<String> consumer = (String s) -> {
        System.out.println(s);
    };
   
    // 【版本2】改成Lambda简写版本
    Consumer<String> consumer = s ->  System.out.println(s);
```

# 方法引用

1. 静态方法引用	类名::静态方法	args -> 类名.静态方法(args)	Integer::parseInt
2. 指定对象的实例方法（绑定实例）	对象::实例方法	args -> 对象.实例方法(args)	System.out::println
3. 任意对象的实例方法（非绑定）	类名::实例方法	obj,args -> obj.实例方法(args)	String::toUpperCase
4. 构造器引用	类名::new	args -> new 类名(args)	User::new

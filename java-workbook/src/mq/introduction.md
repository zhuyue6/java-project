# 什么是消息队列
消息队列就是一个中间缓冲区，生产者发消息丢进队列，消费者异步拉取信息；
对解耦、削峰、异步、可靠投递的特点

## 四个核心角色：
1. 生产者：产生消息的业务服务
2. broker: MQ服务本身（存消息、转发、比如rabbitMq, kafka）
3. 队列： topic/queue 消费存放的容器
4. 消费者：consumer 从队列里面拿消息

## 四大核心能力：
1. 解耦：服务直接不再直接调用，新增下游上游不用改代码
2. 异步：上游不用等待下游处理完，直接返回，提升速度
3. 削峰填谷：流量突然增消息先入队列，消费者匀速消费，防止下游被打垮
4. 可靠投递：支持重试、死信、保证消息至少被消费一次

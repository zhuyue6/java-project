# 泛型特点
泛型是把参数类型化，把类型作为参数进行传递，编译器进行检查，避免强转，使用类型擦除法

## 声明

```java
   // 类定义泛型
   class Box<T> () {
      private T data;
      public T getData() {
        return data
      }

   }

   class Box1 () {
      public <T> T getData(T data) {
        return data
      }

   }

   interface Box2 {
      T next();
   }
```

## 通配符
 
Producer Extends，Consumer Super

```java
   // 无界， 只读不写
  List<?> list; 
  list.get('11') ✅️
  list.add(222) ❌️
  
  // 上界, 属于子类， 只读不写
  List<? extends Animal> list; 
  list.get('11') ✅️
  list.add(222) ❌️

  // 下界, 父类, 只写不读
  List<? super Animal> list; 
  list.get('11') ❌️
  list.add(222) ✅️
  
```

## 泛型擦除

```java
    List<String> list = new ArrayList<>();
    list.add("aaa");
    String s = list.get(0);

    // 等价于
    List<Object> list = new ArrayList();
    list.add("aaa");
    String s = (String) list.get(0);

```

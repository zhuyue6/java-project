# 数组特点
```java
   // 数组声明
   int[] arr1 = new int[5];
   int[] arr2 = { 1, 2, 3, 4, 5};

```

## 循环
```java
    // 索引循环
   for (int i = 0; i < arr1.length; i++) {
      System.out.println(arr1[i]);
   }

   // forEach 增强for, 专门用来遍历数据、list 等实现了Iterable接口的集合
   for (int n: arr1) {
      System.out.println(n);
   }
```

## 实例方法属性
数组只有length属性，没有方法，想操作数组需要使用java.util.Arrays 工具类

```java
  // 常用的数组方法
  int[] arr = {1, 2, 3}
  // 快排
  Arrays.sort(arr)  
  // 全部填充
  Arrays.fill(arr, 66)
  // 比较每一个元素是否相等
  Arrays.equals(arr, arr1)
  // 转换List, 转换的是静态类，而不是ArrayList, 不能add
  Arrays.asList(1, 2)
```

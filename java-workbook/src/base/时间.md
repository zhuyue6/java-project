# LocalDateTime
1. 不带时区，
2. 非线性安全


# api
```java
  // LocalDateTime 日期LocalTime+ 时间 LocalTime
  
  // 获取当前时间
  LocalDateTime now = LocalDateTime.now();

  // 指定时间
  LocalDateTime dt1 = LocalDateTime.of(2026, 11, 9, 17, 30, 0);
  
  // 定义解析格式
  DateTimeFormatter fmt = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
  LocalDateTime parse2 = LocalDateTime.parse("2026-11-09 17:30:00", fmt);

  // 获取字段
  now.getYear()
  now.getMonth()

  // 时间+-
  now.plusDays(1) // +1天
  now.minusDays(1) // -1天

  // 设置
  now.withMinute(0) // 设置时间分为0

  // 时间比较
  t1.isBefore(t2);   // true
  t1.isAfter(t2);    // false
  t1.isEqual(t2);    
```

## TemporalAdjusters
工具类，内置一堆现成的 TemporalAdjuster 实现, 用来配合 `temporal.with(adjuster)` 做时间跳转（LocalDate / LocalDateTime / ZonedDateTime 都能用）
```java

  // 当月第一天
  TemporalAdjusters.firstDayOfMonth()

  // 当月最后一天
  TemporalAdjusters.lastDayOfMonth()

  // 当前本周一天
  TemporalAdjusters.previousOrSame(DayOfWeek.MONDAY)
  
  // 当前本周最后一天
  TemporalAdjusters.nextOrSame(DayOfWeek.SUNDAY)

```
